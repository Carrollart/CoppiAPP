# CoppiAPP — GitHub Pages

## Pubblicazione

1. Vai su GitHub e crea un nuovo repository, per esempio `CoppiAPP`.
2. Carica nella root del repository questi file:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `.nojekyll`
3. Apri **Settings → Pages**.
4. In **Build and deployment**, scegli:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Salva.

Dopo la pubblicazione l'app sarà normalmente disponibile a un indirizzo simile a:

`https://TUO-USERNAME.github.io/CoppiAPP/`

## Installazione sul telefono

### Android / Chrome
Apri il link → menu ⋮ → **Aggiungi a schermata Home** / **Installa app**.

### iPhone / Safari
Apri il link → pulsante Condividi → **Aggiungi alla schermata Home**.

Lo storico viene salvato localmente sul dispositivo tramite `localStorage`.
